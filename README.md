### How I work

- **Security in the database.** Tenant isolation with Postgres Row Level Security, signed webhooks, encrypted secrets.
- **Business rules apart from I/O.** Pure functions with fast tests, and thin server code that reads, calls them and writes.
- **Guard rails in CI.** Build-time checks for permissions, migrations, design tokens and route coverage.
- **Mobile is production.** The users are on job sites and on the road, so phones get the same care as desktops.
